How Claude uses this

Whatever frameworks the user provides get folded into Claude's dimension generation prompt — e.g. "This person is a Scorpio sun with Virgo rising, ENFJ, Enneagram 3w2. Generate scoring dimensions that reflect their drive for impact, sensitivity to authentic mission, and preference for structured execution." The more frameworks they provide, the sharper the dimensions.
