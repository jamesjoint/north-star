Section 2: Auth & Invite Flow (revised)

Two paths in — self-signup with a waitlist, or invite links that skip it

Path A — Self Signup

1
Anyone visits the site

Landing page with a brief description + "Get early access" CTA

2
Enter email → joins waitlist

Account created but in pending state. They get a "you're on the list" confirmation email.

3
You approve them

One-click approval in your admin panel flips their status to active and sends them a magic link to finish onboarding

Path B — Invite Link (skip waitlist)

1
You generate an invite link

From admin panel — unique URL, expires in 7 days

2
User visits link → enters email

Invite code pre-authorizes them — no waitlist, account goes straight to active

3
Magic link → straight to onboarding

No approval step — they're in immediately

Returning login (both paths)

Just an email field → magic link → 30-day session cookie. Same for everyone once they're active.

Your admin controls
  • View waitlist + one-click approve/reject
  • Generate + revoke invite links
  • See all active users + deactivate
  • Scoring queue status
