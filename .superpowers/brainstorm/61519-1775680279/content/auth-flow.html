Section 2: Auth & Invite Flow

How new users get in and how magic link login works

Getting In (Invite Flow)

1
You generate an invite link

From an admin panel or a simple /admin/invites page — one-click generates a unique invite URL with an expiry (e.g. 7 days)

2
User visits the link

They see a simple landing page: "You've been invited to join [app name]. Enter your email to get started."

3
Magic link sent

They get an email with a one-time sign-in link (via Resend — simple email API, free tier generous). Link expires in 15 min.

4
Account created → Onboarding

First login triggers profile setup wizard. Subsequent logins go straight to their dashboard.

Returning Login

1
Visit the app

Unauthenticated users see a minimal login page — just an email field

2
Enter email → get link

Same magic link flow. No password to forget. Only registered emails work — no self-signup.

3
Session cookie set

better-auth issues a session token, stored as an httpOnly cookie. Session lasts 30 days. No JWT complexity.

Your admin controls
  • Generate + revoke invite links
  • See who has accounts
  • Manually deactivate a user
  • See scoring job queue status
